# Remnant

**A Game Project for ANO University Lesson**

## Overview

Remnant is a game development project created as part of the ANO course at the university. This project demonstrates game design, implementation, and software engineering practices using a combination of Wolfram Language and C#.

## Project Description

This repository contains the source code and assets for the Remnant game. The project showcases:

- **Game Mechanics**: Core gameplay systems and mechanics
- **Software Architecture**: Well-structured codebase using C# for game logic
- **Computational Elements**: Integration of Wolfram Language for mathematical computations and algorithm-driven systems
- **Educational Value**: Serves as a practical learning project for understanding game development principles

## Technology Stack

The project is built using:

- **C# (34.4%)**: Game engine integration, game logic, and core systems
- **Wolfram Language (65.6%)**: Computational algorithms, mathematical models, and data processing

## Features

- Interactive gameplay mechanics
- Algorithmic game systems powered by Wolfram Language
- Modular C# architecture for scalability and maintainability
- University-standard code documentation and structure
